# Documentation status

The public documentation set is not yet complete.

Before this repository is made public, this directory must contain reviewed, implementation-matched versions of at least:

- product scope and explicit non-goals;
- architecture and data-flow description;
- access, authorisation and recovery model;
- privacy and deletion explanation;
- self-hosting and update instructions;
- operational release and deletion checks.

Preparation documents are not copied here automatically because they may contain open decisions or refer to unrelated sats4you.ch modules. Every published document must be checked against the actual pulse implementation and hosting configuration first.
