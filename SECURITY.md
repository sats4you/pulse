# Security Policy

## Reporting a vulnerability privately

Please do not publish suspected vulnerabilities as a public issue. Do not include or test real participant, administration or recovery links.

Report security concerns privately to:

**security@sats4you.ch**

Helpful information includes:

- a concise description and potential impact;
- reproducible steps using synthetic test data only;
- the affected version, URL or commit identifier;
- a possible mitigation, if known;
- an optional contact address for follow-up.

Please do not test against real groups or their data, perform availability attacks, or access information beyond what is strictly necessary to demonstrate the issue.

## Handling reports

The project reviews reports as capacity permits. The closed pilot does not promise a guaranteed response time and does not operate a bug-bounty programme. For a confirmed vulnerability, remediation and coordinated disclosure will be discussed with the reporter. Reports and acknowledgements may remain anonymous.

## Supported version

During the closed pilot, only the version currently operated by sats4you.ch is supported. Older commits, third-party deployments and modified forks are outside the operational responsibility of sats4you.ch.

## Limits

Public source review, community reports and automated checks improve security, but they are neither an independent audit nor a guarantee that the software is free of defects.
