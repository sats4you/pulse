# Contributing to pulse

Thank you for helping review and improve pulse.

The project is still preparing a closed pilot. Before public contribution workflows are opened, proposed changes must remain small, reviewable and consistent with the documented privacy and security model.

## Ordinary improvements

- Open a focused issue or pull request once the repository is public.
- Explain the user problem and the intended change.
- Keep unrelated changes separate.
- Add or update tests for changed behaviour.
- Do not add analytics, trackers, remote fonts or unnecessary third-party resources.
- Do not include real participant data, access links, credentials or screenshots containing secrets.

By submitting a contribution, you confirm that you have the right to provide it under the project's `AGPL-3.0-only` licence.

## Security issues

Do not open a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md) and report it privately to `security@sats4you.ch`.

## Product boundaries

The closed pilot serves Bern Monthly Bitcoin Meetup. User accounts, public profiles, chat, reminders, Meetup synchronisation, general self-service group creation and anonymous multi-option scheduling are outside the pilot scope.
